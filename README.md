# zion-ai-threat-modeler
Zion AI Threat Modeler — auto-generated STRIDE threat models from architecture diagrams.

- Live: https://ziontechgroup.com/zion-ai-threat-modeler/

## Features
- Upload or paste architecture diagrams and get STRIDE-based threat models
- Risk-ranked findings with recommended mitigations
- Exportable security reports for audits and compliance
- Integrates with CI to flag risky design changes
